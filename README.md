⚪ Описание проекта:

Этот проект представляет собой список задач (типа to-do list), выполненное на языке программирования Go.

⚪ Структура проекта:

my_go_final_project_todo_list/
├── pkg/
│   ├── api/              # Обработчики HTTP-запросов
│   ├── db/               # Логика работы с базой данных
│   └── server/           # Инициализация и запуск сервера
├── web/                  # Файлы фронтенда
├── test/                 # Тесты приложения
├── main.go               # Точка входа в приложение
├── scheduler.db          # Файл базы данных

⚪ Запуск приложения на Windows (Bash):

1. Клонируйте репозиторий:

`git clone https://github.com/theMastBlood/my_go_final_project_todo_list.git`
`cd my_go_final_project_todo_list`

2. Установите необходимые зависимости:

`go mod tidy`

3. Запустите исполняемый файл:

`go run main.go`

4. Откройте ваш веб-браузер и перейдите по адресу http://localhost:7540.

⚪ Тестирование приложения:

Для запуска тестов выполните следующую команду в корневой директории проекта:

`go test ./test`
